📘 About the Project

This is a simulated front-end interface built as a single HTML file to demonstrate a UI independently from the Python/Streamlit backend.

Actual capabilities in the backend Python version:

  • Real-time exact predictions using a trained Scikit-Learn `RandomForestRegressor`.
  • Feature scaling, imputation, and categorical label encoding in a data pipeline.
  • Comprehensive Exploratory Data Analysis using Seaborn, Matplotlib, and Plotly.
  • Interactive live tables using Pandas.
